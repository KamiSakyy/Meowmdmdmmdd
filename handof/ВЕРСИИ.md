# Архивы исходника MDGram (папка handof)

Каждая сборка складывает сюда **полный ZIP текущего исходного кода**:

| Архив | Что внутри | Размер |
|---|---|---|
| `MDGram-source-v1.zip` | полный Gradle-проект MDGram (1967 java, 6221 res, нативные .so), keystore, документация | 72 МБ |

Состав архива:
```
MDGram/            — чистый Gradle-проект (settings.gradle, build.gradle, gradlew)
  app/src/main/java — 1967 java-файлов (движок Telegram 9.3.3 + пакет org.telegram.mdgram)
  app/src/main/res  — 6221 ресурс (layout/drawable/values/themes)
  app/src/main/jniLibs — нативные .so (arm64-v8a, armeabi-v7a, x86, x86_64)
mod-keystore/      — ключ подписи
PROGRESS.md, ИНСТРУКЦИЯ.md, README.md, PORT_PLAN.md
```
Ни smali, ни dex внутри нет (проверено: 0).

## Как собрать из архива
```bash
unzip MDGram-source-v1.zip
cd MDGram
./gradlew :app:assembleRelease
# готовый APK: app/build/outputs/apk/release/app-release.apk
```

## Правило версий
Номер версии растёт на 1 при каждой успешной сборке (файл `handof/VERSION`).
Следующий архив: `MDGram-source-v2.zip`, затем v3, v4 и т.д.
