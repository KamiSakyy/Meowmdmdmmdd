# handof — версии исходника и APK MDGram

Каждая версия — отдельный файл. Не перезаписывать старые.

| Файл | Что внутри |
|------|------------|
| `MDGram-source-v1.zip` | Снимок `MDGram/` до доработки MD-слоя (движок 9.3.3, только `MDConfig`) |
| `MDGram-source-v2.zip` | Полный Gradle-проект: MD-экраны, хуки drawer/ghost/stickers, строки, wrapper |
| `MDGram-apk-v2.apk` | Сборка Android SDK (GitHub Actions, JDK 11, AGP 7.4.2) после v2 |
